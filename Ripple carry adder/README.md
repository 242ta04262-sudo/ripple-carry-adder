Ripple Carry Adder
Overview

This project implements a 4-bit Ripple Carry Adder (RCA) using Verilog HDL.

A Ripple Carry Adder is a digital circuit used to add two binary numbers. It is constructed by connecting multiple full adders in series. The carry output generated by one full adder is connected to the carry input of the next full adder.

The main objective of this project is to understand the operation and implementation of binary addition using combinational digital logic.

Features
4-bit binary addition
Implemented using Verilog HDL
Built using four 1-bit full adders
Supports carry input
Produces a 4-bit sum and carry output
Includes a Verilog testbench
Includes waveform simulation

Full Adder Logic

Each full adder has three inputs:

A
B
Carry-in (Cin)

and two outputs:

Sum
Carry-out (Cout)

The Boolean equations are:

Sum  = A XOR B XOR Cin

Cout = (A AND B) OR (B AND Cin) OR (A AND Cin)
Working Principle

The first full adder receives the least significant bits of A and B along with the external carry input.

The carry generated by the first full adder is passed to the second full adder.

The process continues until the most significant bit.

Therefore, the carry propagates through the chain of full adders, which gives the circuit its name Ripple Carry Adder.

Input and Output
Signal	Width	Description
A	4 bits	First binary number
B	4 bits	Second binary number
Cin	1 bit	Input carry
Sum	4 bits	Addition result
Cout	1 bit	Final carry
Example

For:

A   = 0101
B   = 0011
Cin = 0

The addition is:

  0101
+ 0011
-------
  1000

Therefore:

Sum  = 1000
Cout = 0

Advantages
Simple design
Easy to understand
Requires relatively little hardware
Easy to implement for small bit widths
Disadvantages

The main disadvantage is propagation delay.

The carry must travel through each full adder before the final result is available. As the number of bits increases, the delay also increases.

For example, in a 4-bit RCA:

FA0 → FA1 → FA2 → FA3

The carry generated at FA0 may need to pass through all subsequent stages.

Conclusion

A 4-bit Ripple Carry Adder was successfully designed and simulated using Verilog HDL. The design uses four full adders connected in series, with the carry output of each stage connected to the carry input of the next stage.

The simulation results verify that the circuit correctly performs binary addition for different combinations of input values.
